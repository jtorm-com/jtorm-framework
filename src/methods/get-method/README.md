# jTorm Get Method

## Install
```js
npm install jtorm-com/jtorm-get-method
```

## Properties

| Option | Type                  | Required | Description        |
|--------|-----------------------|----------|--------------------|
| `h`    | `string`              | `false`  | HTML template path |
| `t`    | `string/array/object` | `false`  | TSS path(s)        |
| `d`    | `string`              | `false`  | Data path          |
